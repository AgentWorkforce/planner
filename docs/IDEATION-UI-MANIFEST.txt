⚙️  CORE SYSTEMS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. PHYSICS ENGINE (usePhysicsEngine)
   Library: matter-js
   Features:
     • Zero gravity (custom forces only)
     • Central attraction: 0.00008 (drift to center)
     • Initiative grouping: 0.00015 (cluster by initiative_id)
     • Edge attraction: 0.00012 (for abandoned)
     • Collision detection (circles)
     • Wall boundaries (containment)
     • Mouse constraint (draggable)
   Desktop: Enabled
   Mobile: Disabled (performance)

2. REAL-TIME UPDATES (SSE)
   Endpoint: EventSource /api/ideation/sessions/{id}/events
   Events:
     • session:block_created
     • session:block_updated
     • session:block_deleted
     • session:transcript_updated
     • session:understanding_updated
     • session:status_changed
   Reconnect: Exponential backoff (3s, 6s, 12s, cap)

3. FOCUS MODE (URL + Component State)
   Route: /ideation/session/:id?block=:blockId
   Layout: 60% detail panel + 40% chat sidebar
   Features:
     • Editable markdown content
     • Block metadata display
     • Curate button (primary)
     • Close button (exit focus)
     • User edits timeline

4. STATE MANAGEMENT
   URL:          /ideation/session/:id?block=:blockId
   LocalStorage: ideation-panel-collapsed, theme, user settings
   Hooks:        blocks[], session, understanding, confidence
   SSE:          Real-time updates for blocks, transcript, understanding
